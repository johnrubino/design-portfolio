What I think
  1. Process dictates tooling.Shipping inside a locked design system and inventing outside it are different skills, so I pick the starting line per mode.Figma isn’t always the starting line
  2. Orchestrate, then judge.Outcome clarity, system awareness and direction-setting get work moving; output judgment, where taste and domain expertise live, decides if it’s good.From Pixel Pusher to Orchestrator
  3. Design the substrate, not just the surface.As interfaces get generated at runtime, the design moves into the rules and context that decide what shows.The Interface Is Disappearing
  4. Handoff is a communication problem.No single tool fixes it. Clear freeze points, branches and edge-case specs do more than another plugin.The Dev Mode study
