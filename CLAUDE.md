# Notes for AI assistants

- **Case-study image placeholders:** `hiring.html` marks missing images with comments like `<!-- 📸 IMAGE PLACEHOLDER [FOWA-05]: ... -->`. When asked to add an image "for placeholder X" (by ID, or by describing it), look up the ID in the table at the bottom of `HOW_TO_ADD_IMAGES.md`. Then replace that comment in `hiring.html` with the `<figure>` snippet inside it, and remove the row from the table.
- Never add visible `.image-placeholder` boxes to `hiring.html`; hiring managers see that page.
